# 精神传承首屏：从历史走向未来

保留原山河艺术场景和杭电问鼎广场照片、图片裁切、背景融合、书法字体、正文、双周年纪念与顶部导航。原红旗属于山河合成图，未另做旗面或添加粒子。短横屏仅收紧首屏垂直留白，把「暂停光影」和继续阅读留在视口内。后续章节的文案、布局及素材未修改。

| 时间 | 浏览器实际效果 |
| --- | --- |
| 0–0.8s | 墨黑遮幕退去，山河先显；两张图在同一个平面上由 1.035 缓慢归到 1，约 1.8s 完成，避免接缝错位 |
| 0.6–1.8s | 原图片的融合边缘保持，额外柔边遮罩沿校园图层横向推进。校园透明度恢复原值，中央短暂带一点暖金；竖屏沿原有上下拼接方向揭示 |
| 1.42–2.6s | 四字原字形依次显现，间隔 100ms、位移 8px；每字用裁切和淡入，桌面轻微去模糊，紧凑和触摸设备省略模糊；副标题原两行接续淡入 |
| 2.4–3.26s | 双周年标记间隔 220ms，以 7px 位移及淡入依次显现 |
| 3.24–4.2s | 阅读提示淡入；接续原有箭头微浮和校园缓慢光影 |

复用项目 GSAP，在首屏范围内建立一条 4.2 秒时间轴。进入、暂停、结束分别对应明确状态。暂停同一条时间轴，恢复从原点位继续，不重新启动阅读红线或电路观察器。跨章重新进入首屏会播放；原暂停偏好仍开启时展示静态首屏。章内跳转、深链、快速离开画面、后台和减少动态效果均落到完整画面；恢复系统偏好不会突然补播。没有新增依赖、滚动锁、常驻帧循环或替换素材。

实际使用的 Skills：`frontend-design` 用于沿用墨绿、暖金与原版式，只把视觉重点集中于图像交接；`cinematic-scroll-storytelling` 用于五幕重叠节奏、错时字形揭示、GSAP 局部清理及紧凑设备降级。
