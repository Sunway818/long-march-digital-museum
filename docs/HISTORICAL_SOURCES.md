# 历史资料来源与核验登记

日期：2026-11-06。当前建立来源管理方法和候选入口，尚未建立可直接发布的事实库。

## 来源优先级

1. 权威党史、军史著作、档案及正式出版史料，保留版本、卷册和页码。
2. 中央党史和文献研究机构、官方军史机构、长征相关纪念馆/博物馆公开资料。
3. 官方媒体的专题、访谈、史料介绍，追溯其引用原稿。
4. 学术研究作为补充，记录作者与出版信息；个人博客、商业地图和无出处短视频只可作检索线索，不作为最终唯一证据。

## 引用与复核规则

- 页面摘要采用可追溯转述；直接引语逐字比对，适度引用并显示出处。
- 内容编辑、日期审核、地理审核和媒体版权状态分别记录，不能互相替代。
- 发现矛盾保留两种表述和出处，不靠多数转载决定真伪；选择展示口径时写明依据。
- 链接失效先记录失效时间，再查机构档案/正式出版物，保存允许保存的证据摘要；不绕过访问限制。
- 同一事件不同部队的到达时间不能互相复制；地图插值属于展示方法，不能倒写成史实。
- 第 12 天冻结正式引用清单，报告参考文献与网站来源使用同一组 Source ID。

当前没有 verified 的具体史实条目；后续正式采集从此登记表与 [数据计划](HISTORICAL_DATA_PLAN.md)共同推进。
