32段方向数据只在**同军、相同端点、无分叉**时串接为一条GeoJSON笔画，避免每个短段重启虚线和箭头。总览得到5条笔画：中央、红二及前身、红二十五军各1条，红四分2个阶段。时间演进、隐藏军队和阶段选择仍按原日期/集合派生，未来方向不提前出现。

**这不是四条完整精确道路的重建。** 扎西至会理包含四渡赤水反复转战，盘县至甘孜涉及两个军团分路，庾家河后包含根据地时期往返，均仅表达阶段首尾方向。红四方面军1935年会师后的南下/再北上缺口未跨接；没有用懋功直连甘孜。没有根据相邻行号自动补线、改动史实日期或偏移节点。界面常驻精度说明，帮助中明确这些省略和缺口。

## 精选节点规则

`featuredEvents.ts`集中维护有来源定位的选读说明，`curation.ts`只收录有日期、现有地域坐标、至少40字符有效说明及可追溯来源的条目，排除通用模板说明。采用人工明确的精选清单而非按所有行强行填充。新增说明依据已登记来源编写，仍属待审核展陈稿，不修改原summary、日期或verification_status。

当前16项：EVT-006、125、128、019、001、002、106、049、053、150、065、072、084、100、076、077（列表按已有日期锚点排序）。涵盖于都、何家冲、独树镇、黎平、遵义、扎西、嘉陵江、泸定桥、懋功、永坪、哈达铺、吴起、桑植、甘孜、会宁和将台堡的地域参考。

只有模板、无法定位的事件不再进入右侧主索引；156项原始事件仍完整存在，同地域地图选择器及前后事件仍可打开相关原始记录，详情注明未纳入精选及待补证据。精选不表示坐标精确或史实审核完成，争议日期原样保留。影像仍仅本机研究预览，不转移到public，不改变审核或版权状态。
