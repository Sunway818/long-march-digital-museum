## 视觉原则

历史厚重感、电影叙事感、数字科技感、沉浸体验。深红、暗金、黑色构成主调；大尺寸史料影像与档案式版式服务叙事。每屏承担一个主叙事任务，标题、影像和正文具有明确层级。

避免后台式导航框架、重复卡片矩阵、廉价渐变、无意义纹理和复杂 3D 堆砌。资料卡仅用于真实需要独立阅读的档案信息。高质量不等于处处动画。

## 组件与状态

- 导航：当前章节、悬停、键盘焦点、缩窗换行状态；提供跳到正文入口。
- 按钮：主要、次要、图标三类；播放、暂停名称跟状态同步；禁用状态有原因。
- 时间轴：当前日期、有效范围、可操作滑块、前后事件按钮；说明键盘操作，显示日期精度。
- 地图：完整边界、路线图例、缩放复位、地点、选中和待核验标识；有等价事件列表。
- 资料面板：标题、日期、部队、正文、媒体、引用、关闭；大屏右侧非模态，缩窗时采用页面内堆叠资料栏。
- 空状态/错误：明确“无可见部队”“该时段无可确认位置”“影像加载失败”；不可用装饰替代信息。

统一处理 default/hover/focus/active/disabled/loading/error，不仅设计静态截图。建议交互命中区至少 44×44px，正文对比度目标 4.5:1，大文字和非文本界面目标 3:1；实际组合以测量为准。

## 动画原则与分工

动效表达时间、空间和信息关系；入场不可阻止阅读。候选时长：控件 150–250ms、面板 250–400ms、主题转场 600–1000ms，最终以可读性评审调整。主叙事可使用 GSAP ScrollTrigger；局部面板可评估 Motion；同一 DOM 属性只能有一个动画所有者。

只对必要对象使用 transform/opacity；避免大面积实时模糊。Lenis 作为渐进增强，不接管地图拖动与面板内滚动。尊重 `prefers-reduced-motion`：取消视差、强制平滑滚动和大幅章节固定，保留完整内容。预加载器只能反映真实资源状态，允许跳过/超时退出，不制造虚假进度。

实际下载并渲染了 Google Fonts 官方仓库中的 ZhiMangXing-Regular.ttf（内部中文名“钟齐志莽行书”）、MaShanZheng-Regular.ttf、LiuJianMaoCao-Regular.ttf，四字 glyph 均非零。见[实际字体对比图](design-review/font-comparison.png)、[渲染证据](design-review/font-render-report.json)、[本地原图构图评审](design-review/font-comparison.html)。这三个文件是设计评审依赖，不代表网站已经加载这些全量字体；不修改系统字体。

实际字形判断：志莽的“伟”“程”笔画饱满、行气自然，“大”字留白较多，宜略缩紧“伟—大”与“大—征”的视觉空隙；马善政结体更正、四字字面更均衡，笔画清楚，作为纪念标题稳健备选；流建毛草的“征”“程”草化明显，细笔与背景云层相遇时更容易损失辨识，不建议作为教师首次阅读的主标题。用户已选择 A 钟齐志莽行书；马善政与流建毛草仅保留对比记录。字号、字距与位置仍需在桌面原型中校准。

三套实际字体均保留官方 OFL.txt 与 METADATA.pb，来源、SHA 与完整大小见评审说明。思源[宋体许可](https://raw.githubusercontent.com/adobe-fonts/source-han-serif/master/LICENSE.txt)、[黑体许可](https://raw.githubusercontent.com/adobe-fonts/source-han-sans/master/LICENSE.txt)沿用 OFL 1.1 核验结果。最终获取真实思源部署包时仍需核对名称、字形、版本和大小，不将系统 Noto 字体冒称思源实际部署文件。

正式网页后续采用合法自托管字体、保留许可、font-display:swap；书法只为四字制作子集须另行核查保留名称要求，不擅自改字体。评审目前是全量 TTF；实际加载性能、WOFF2 与子集尚未验证。

## Desktop-first 布局与缩窗韧性

1920×1080 是设计画幅，Windows 桌面 Chrome/Edge 优先；屏幕分辨率不等于实际 CSS 视口，必须另记录 Windows 缩放、浏览器 zoom、innerWidth/innerHeight 和 F11。正文与控件以真实可读尺寸为准，不按整页 transform 缩放。

| 场景 | 留白/最大内容 | 导航与布局 |
| --- | --- | --- |
| 1920×1080 | 两侧 96px，内容最大 1728px | 72px 导航，12 栏，24px 栏距；全屏电影式首页 |
| 1536/1440 宽窗口 | 两侧 64px | 同一桌面导航与地图结构，标题/间距有限收缩 |
| 1366×768 | 两侧 48px | 导航 64px、地图右栏 320px，控件允许换行；内容高度不足自然纵向滚动 |
| 1024×640、800×600 缩窗 | 两侧 24px | 导航自然换行；地图与资料栏上下排列、正文自然增长，不建立手机专属菜单或手势体系 |

所有宽度下网格列可收缩，长链接断行，flex/grid 子项 min-width:0；媒体 max-width:100%，不靠 overflow:hidden 掩盖正文裁断。首屏以 min-height:100svh，窗口很矮时允许内容增高。正文最大 760px，人物/长文可保留既有分栏后自然堆叠。1920 与 1366 的标题、副标题、按钮都应能阅读，200% 文字缩放保留操作入口。

不专门设计手机导航、移动地图和底部对话框。未来小屏完整影像带与底部对话框保留为已原则认可的候选；若另行启动手机适配，须测试可读性、操作便利和地图可视面积，当前没有相关实现或验收结论。

叙事图 16:9、档案原件完整展示、肖像建议 3:4；固定图片占位。原图 1672×941 在 1920 显示会放大约 1.15 倍，细节锐度需要现场判断，不进行 AI 放大或制作压缩派生图。用户未确认原图权利前，不复制到公开资源目录、不导出合成背景、不部署。

章节保持单一叙事任务，长文自然增长，不强制轮播翻屏。桌面动效可保留短入场、背景轻缩放和克制视差，但地图/详情不能锁住整页。

2. 右侧文字区域铺炭黑局部遮罩，最弱处等效不透明度至少 72%，边缘向画面非文字区柔和过渡；左侧不铺同等强度，保持红旗细节。它只解决对比度，不加入装饰彩虹渐变。以最亮白底估算合成为约 #535151，米白字对比约 6.77:1；实际仍需截图像素验证。

4. 入场先静态可读，标题透明度和 12px 位移在 800ms 内完成，副标题延后 100ms，控件不等待动画才可点击。背景仅在首个 900ms 从 1.02 缩到 1，不循环放大；滚动时最多 ±16px 的装饰视差，不驱动历史日期。
5. 1920×1080 与 1366×768 均接近原图 16:9，浏览器显示采用 cover、object-position:45% 50%，旗帜/人物留左，太阳不盖字。书法标题约 x=58%、y=23%，标题底部保持在山脊上方；1920 用 156px、1366 用 112px 起评。字面可缩进右侧列而不能跨进 x<50% 的红旗区。不同字号由实际字体测量，不假定四字都等宽。
6. 缩窗时优先保持人物安全区与文字可读，必要时图文上下重排并允许纵向阅读，不增加手机专属导航或底部对话框。未来手机影像带仅为候选，不参与本轮验收。
7. 优点：保留画面叙事张力，视觉重心平衡，进入动作明确，与后续深色地图连贯。风险：云层和屏幕比例变化影响对比度及裁切；需 Day 3 真正加载字体后做截图校准。

## 动画规范表（只规划）

| 动画/目的 | 触发 | 持续/幅度 | 缓动 | 性能与减少动态效果替代 |
| --- | --- | --- | --- | --- |
| 首页标题：建立阅读起点 | 首次进入且关键图可用 | 800ms，y:12→0，opacity:0→1 | power3.out | 内容先存在；reduce 立即显示；不逐字拆坏中文语义 |
| 背景缩放：轻微空间感 | 首屏初次进入 | 900ms，1.02→1，仅一次 | power2.out | 仅 transform；reduce/低性能静止；不超过 5s 循环 |
| 图片视差：层次 | 桌面主动滚动且章节可见 | 跟随滚动，±16px | none | 原图是单层，不抠人物做假深度；reduce/低性能关闭 |
| 章节过渡：提示阅读切换 | 进入章节可见区 | 400—600ms，opacity/小位移 | power2.out | 仅重点章节；正文默认可见；reduce 立即到最终态 |
| 文字逐段：建立层级 | 一次进入关键叙事段 | 400ms，段间 80ms，最多 3 段 | power2.out | 不每字拆分，不隐藏长文；reduce 无入场 |
| 时间轴反馈：确认操作 | pointer/键盘输入 | 日期即时更新，滑块强调 120ms | ease-out | 不延迟实际时间；reduce 无缩放，用轮廓表示 |
| 地图路线绘制：表示历史推进 | SEEK/播放 | 对应 currentDay，无额外拖尾缓动 | linear/none | 预计算分段，不每帧重建底图；reduce 仍响应显式调时 |
| 地点出现：提示新事件 | 到达已审核 revealDay | 160ms opacity，位置固定 | ease-out | 同时大量出现不做连锁弹跳；reduce 直接出现 |
| 资料卡展开：建立选择关系 | 明确激活地点/事件 | 280ms，局部 x:16→0 | cubic-bezier(.22,1,.36,1) | 桌面保留列宽避免地图逐帧重排；reduce 立即展开 |

GSAP/ScrollTrigger 管章节，局部面板可评估 Motion，原生 CSS 管 hover/focus；同一属性只有一个所有者。Lenis 最多一个实例，可完全关闭；历史模拟独立单 RAF。离开视口/后台停止非必要效果；卸载清理 ticker、监听器、ScrollTrigger。禁止所有卡片反复滑入、按钮持续发光、强制音频和没有真实进度的加载器。

## 统一组件与其他章节

- 档案面板：表面底+1px 装饰边线，标题区 24px 内边距，正文不塞进第二层卡片。来源链接可聚焦并清晰标记，完整出处不隐藏在 hover 中。
- 时间轴：16px 可见圆滑块配 44×44px 命中区，轨道厚 2px/有效进度 3px；当前日期 20px 黑体 500，次级刻度 14px。重要节点与可拖动滑块形状不同，密集时合并刻度而不删事件。
- 地图底图：暗场平面轮廓，不加发光网格/地球自转。按正规来源展示完整中国地图范围、必要附图和说明，底图待核验，不以手绘边界替代。
- 地图内历史时间轴：时间节点与地图共享状态，日期/功能入口黑体，事件叙事宋体，不再设置独立章节。
- 地图内历史瞬间：战役、会议与重大事件保留背景/意义/引用层级，在地点卡片与事件详情展示。档案保留全貌，无图时用文字，不拿无关场景填补。
- 英雄人物：人物肖像、姓名、任职时期与贡献形成档案页，桌面 4:8 分栏，缩窗后肖像在上；相关事件作为引用式链接，不做重复悬浮人物卡墙。缺肖像保留姓名与文字，不生成伪历史照片。
