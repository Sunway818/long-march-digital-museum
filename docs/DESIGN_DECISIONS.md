### 三套实际字体对比与结论

已下载 Google Fonts 官方仓库实际 TTF 与各自 OFL 1.1/METADATA.pb。通过 Windows GlyphTypeface 验证四字都有真实 glyph，Windows GDI+ 从 PrivateFontCollection 的实际字体轮廓渲染，不靠系统回退，不合成粗体。

| 方案 | 实际文件与内部名称 | 观察与建议 |
| --- | --- | --- |
| A | ZhiMangXing-Regular.ttf；钟齐志莽行书 | 笔画有力量且行气自然；“大”较疏，不能机械加很大字距；用户已确认采用 |
| B | MaShanZheng-Regular.ttf；实际内部名以渲染报告为准 | 结体较正、四字清晰均衡，笔画更稳定；严肃纪念场景的稳健备选 |
| C | LiuJianMaoCao-Regular.ttf；实际内部名以渲染报告为准 | 草化明显、部分细笔与云层叠放可能损失可辨性；不推荐作为首次阅读主标题 |

比较采用同字号 156px/112px、同 6px 字距与原生 400 字重，上行米白、下行暗金；不同字体实际字面不同，不能只按 CSS em 等宽推断。志莽优先在 0—8px 中做光学微调，不压缩横向比例、不描边破坏飞白。实际预览见[字体对比 PNG](design-review/font-comparison.png)，原始 glyph ID、文件 SHA、字面 bounds 见[渲染报告](design-review/font-render-report.json)。

可在本机打开[字体与原图构图评审页](design-review/font-comparison.html)切换实际字体和字距、对照原图及安全区。该文件仅是设计评审工具，非完整首页；没有业务依赖、远程调用或图片导出。PNG 已渲染并查看，HTML 的 Chrome/Edge 加载与真实截图验收仍待用户查看/后续验证，不能声称已经完成浏览器适配。

原图只读取样得到旗帜偏暖暗红 #6D150B/#69180C，天光为 #DEB78B/#FAE7B1；原深红 #8F2635 比原图旗帜偏冷，新增暖红 #8A2E22 候选。暗金 #B99A61 与图中天光协调，建议大标题优先米白、金色用于年份与辅助强调；金色叠亮天空需遮罩，不能仅凭配色方向视为对比已通过。样点不代表全图平均色。
