## 响应式与浏览器矩阵

主画幅 1920×1080，必须兼容 1366×768；补测 1536×864、1440×900、1280×720。桌面浏览器窗口缩到 1024×640、800×600，检验导航可换行、正文自然增长、地图与右栏必要时上下重排，无严重重叠、文字截断和页面横向溢出。允许纵向滚动，不用隐藏 overflow 掩盖布局问题。

Windows 桌面 Chrome 和 Edge 为必测；Firefox 可补测，Safari/iOS/Android 不设本轮门槛。记录屏幕像素、Windows 100%/125%/150% 缩放、浏览器 100% 与 125% zoom、innerWidth/innerHeight、F11 状态、浏览器版本和提交。200% 文字放大与键盘可访问性仍必须测试。

不测试手机专属菜单、移动地图手势、横竖屏切换或底部资料对话框。它们仅为未来候选；若用户另行启动手机适配，再补充 390px 等实测，并检查文字可读、可关闭/可键盘替代、地图可视区域与操作便利，不能把候选认可当作验证通过。

## 性能方法与预算

第 11 天固定构建产物、本机/部署地址、浏览器、CPU/GPU、硬件加速和网络限速设置。使用桌面 Lighthouse 同一设置跑 3 次取中位数，保留原报告；不以移动模拟作为本轮门槛。LCP≤2.5s、CLS≤0.1、TBT≤200ms 为实验室目标；真实 INP 需 field 数据，不以分数代替现场结果。

候选资源预算：初次静态主图≤500KB、首屏所需传输≤1.5MB、初始 JS gzip≤250KB（地图分包另计）；第 3/4 天依据实测调整并记录理由。不要为达预算损害文字和史料可读性。

DevTools 录制地图连续拖动 10 秒，观察帧率、长任务和输入反馈；目标 50–60fps，持续低于 30fps 必须降低效果或数据粒度。检查内存与动画清理，重复进入模块至少 10 次。每项结果附设备和版本，当前不填虚构数值。

## 标题字体与背景图保护检查

- 至少三套实际 TTF/OTF 加载，核对“伟大征程”四字 glyph ID 非零、字体内部名称与 SHA-256；禁止依赖回退字体或人工合成粗体。预览字号 156px/112px，固定同字距，以比较飞白、笔画、字面和可读性。
- PNG 字形预览仅含文字，不含用户背景像素；本地评审 HTML 只读原图、不截取/压缩/导出合成背景。原图 SHA-256 应保持 `f9dd8a4659a5ddb27c909e791a0630e8e4a5b054b00cd9fd73fa51d151935c37`。
- 1920 画幅标题安全区约 x=58%—94%、y=20%—45%；1366 画幅相应缩放并检查真实字面不压红旗、旗手或太阳。正文宋体与控件黑体不混用。
- 当前已完成 Windows GDI+ 实际字体轮廓渲染、四字存在与无裁断检查；报告见 [font-render-report.json](design-review/font-render-report.json)。尚未完成评审 HTML 在 Chrome/Edge 的字体加载与截图验收，不能把 PNG 输出等同浏览器验收。
