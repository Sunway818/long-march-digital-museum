## 设计与实际编排

类型为历史数字展览，主任务是连续阅读一渡赤水的背景、行动变化与解释。没有套用商业网站模板、随机布局、装饰印章或生成影像。frontend-design、design-taste-frontend 的图像主导与版式取舍用于样板设计，UI/UX 规则用于键盘、焦点、阅读宽度和降级；按用户要求保留图注、真实资料性质和长篇内容，不采用技能中与本项目冲突的无图注、商业页面模板及固定整屏内容裁切规则。

| --- | --- |
| 墨黑展墙 | #191818 |
| 暗红分析区 | #552524 |
| 纸面正文 | #EEE9DF，减少黄色 |

展厅92vw × 92dvh，最大1920px宽。固定上沿提供返回地图，内部原生滚动，不增加页面路由或新的滚动动画系统。

叙事顺序：

1. 墨黑开场与大幅渡口地域照片，书法标题、日期、地域、部队与历史问题。照片不加泛黄滤镜，原图未改写；边缘暗场只用于保证文字对比度。提供完整照片查看入口。
2. 独立宋体导语与集中阅读的背景段落，随后以日期侧题与行动过程形成新的排版节奏。
3. 现代整理路线图成为大幅展品，旁文说明1935年1月19日至2月7日的图示范围，以及现代整理图与历史原件的区别。
4. 暗红“本站解读”区，分析与史实分开，保留原创草稿中关于改变方向和连续机动的两段分析；技术性说明不再混在历史分析结尾。
5. 文末折叠史料目录保留原事件、精选说明、正文与影像关联的全部来源；简洁数字出处按钮打开目录并聚焦相应条目。前后事件为轻量编辑式导航，位于阅读尾部。

图片查看为独立近全屏黑色展墙，可前后切换、用查看区左右键切换、放大后滚动及适应窗口。Escape先关图片再关展厅，关闭图片恢复出图按钮焦点；关闭展厅恢复“深入了解”。阅读内前后事件不调地图日期或镜头。
