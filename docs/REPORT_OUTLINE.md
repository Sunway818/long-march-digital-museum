# 大学课程实践报告大纲

本文件保留写作提纲，实际交付文本见[课程实践报告](COURSE_PRACTICE_REPORT.md)。作者信息、学校模板与签字页按真实课程要求填写。

## 1. 项目背景与实践目标

长征胜利九十周年主题、数字展陈的意义、受众和课程目标；项目范围、14 天周期与最终交付物；真实团队分工与本人贡献。

## 2. 需求分析

用户场景、四模块信息结构、核心创新“时空长征”、时间轴和历史事件整合地图的范围调整、功能优先级、非功能与真实性约束。引用 REQUIREMENTS 的 FR/NFR 编号。

## 3. 总体设计

信息架构与章节导航；视觉设计与设计令牌；前端分层和组件结构；历史数据实体关系；MapLibre WebGL、GeoJSON 图层及时间状态流；SVG 用于专题示意图。

图表候选：信息架构图、组件关系图、状态流图、历史数据关系图。标清实际实施版本，与最终源码一致。

## 4. 关键技术实现

工程与构建；日期归一化；时间轴拖动；多部队分段路线的时序裁剪；地图/事件双向联动；自动播放和倍速；详情面板与筛选；动画清理和渐进增强；响应式与键盘操作。

选取必要短代码解释算法、状态边界和设计取舍，不粘贴大量完整源码。分别说明历史真实节点与展示插值，不能把插值算法描述成复原精确每日行军轨迹。

## 5. 功能展示

首页、时空长征（地图内时间轴、地点事件详情和多部队筛选）、人物、精神传承；桌面与缩窗截图、核心流程演示。截图标注版本，未完成项不得编造截图或成效。

## 6. 测试与优化

测试环境、用例与需求对应表、通过/失败/未测结果；响应式、键盘和减少动态效果；浏览器矩阵；性能测量方法与真实数值；典型缺陷、修复及优化前后对照。实验室数据和现场数据分开陈述。

## 7. 历史资料与素材管理

权威资料选择、关键事实核验、路线精度、分歧处理、图片类型与授权署名；资料局限和地图示意的边界。参考文献与网站 Source ID 互相对应。

## 8. 实践总结与展望

实际完成目标、技术与协作收获、存在问题、时间分配和改进方向。单部队模式等若延期如实列出，不将未来功能写成成果。

## 9. 参考文献与附录

按课程要求整理书籍/网页/档案/图片来源。附安装与运行说明、Git 版本、关键测试表、数据字典、任务计划与实际差异、AI 辅助工具/Skills 的使用范围（按学校规范说明）、素材权利清单。
