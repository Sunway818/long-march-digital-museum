## 数据与审核边界

原始工作簿和七份导出 JSON 保留。运行时显示157项事件，156项地点记录中70项带地域坐标、86项暂缺。另有8个仅用于绘线的地域参照点。原始17段中的7条粗线在绘图时由细分方向取代，现有61段、10条独立笔画。分兵、南返、再北上与两支接应部队各自具有时间范围。

本轮地名记录在 [campaign-references.json](../src/data/history/map/campaign-references.json)，逐项列有 GeoNames ID 和 WGS84 坐标。33条地点参考与8个绘线路标均已与本地 CN.zip 比对，经纬度及地物类型一致。原始七份 JSON 的 SHA-256 与上轮留档一致。新的来源沿用 SRC-0082 至 SRC-0090。部分官网正文访问超时，对应条目同时保留索引摘录与已有来源，尚待原件复核。

路线表达区域之间的行动方向，月份或区间锚点只用于时间轴。石棉代表安顺场所在县域，不能当作渡船位置。红四方面军北上仅选绘代表纵队，乌蒙山回旋与丽江多个渡口、红一方面军各接应支队也没有逐日复原。历史确址、原始命令和最终发布审核仍待补充。
