# 《伟大征程》课程实践报告

杭州电子科技大学学生课程实践项目，主题为纪念中国工农红军长征胜利九十周年。作者、班级、课程、实际分工与评分要求由提交人填写，本报告不推定。

## 实践目标

将时间、地理和人物放在同一个参观流程中，让首次来访者能从一段路线进入一份史料，再回到地图理解与前后事件的关系。精神传承以长征精神、杭电建设者的嘱托和青年答卷收束，明确区分历史处境与当代学习实践。

## 已实现功能

首页提供四章入口和影像说明。时空长征用 MapLibre WebGL 渲染本地地理和路线图层，展示四支部队、事件索引、统一时间轴、四渡赤水专题与档案。时钟、日期、筛选与路线裁切共享一套历史状态；地图投影与手势由引擎处理。展品地址可在新会话直达。人物馆包含 16 人肖像墙及档案，可通过人物事件进入地图。精神传承以五个维度、校史素材、遗训和当代答卷串联；纪念笺在设备上生成 PNG，无登录或文字上传。

## 史料选择与展示尺度

主时间轴以1934年10月10日中央红军开始战略转移为参观起点；更早的红六军团先遣仍可在原资料和全程总览阅读。区分瑞金等地出发、于都集结与分批渡河，不给各支部队套用同一天。地图以现代地理提供方向参照，虚线、时间裁切和节点不可作为精确史址或逐日行军事实。档案区分史料、遗址或复原影像、现代示意和本站解读。详见[时间与来源登记](HISTORICAL_SOURCES.md)和[影像清单](FINAL_MEDIA_REGISTER.md)。

## 性能、测试与实际限制

项目沿用 React、TypeScript 与 Vite，使用 GSAP 编排视觉动效，并响应减少动态效果。移动地图将节点避碰与箭头生成移出手势帧，地图本身保持原生双指缩放。[触控性能记录](MAP_TOUCH_PERFORMANCE.md)提供诊断、前后追踪与实验边界，降速浏览器数据不代表手机帧率。[本次验收记录](FINAL_ACCEPTANCE.md)列明实际验证环境、结果、尚待确认项目和演示入口。

## 实践总结

课程价值主要来自把可追溯史料组织成可操作的阅读过程。一次产品走查发现，功能存在本身并不足以让首次使用者理解播放状态、定位同一展品或发现下一步。交付版将这三件事放到参观动线里。长征路线的精细复原、部分素材许可及真机实地验收仍需独立补证。
