# 长征时空地图视觉与信息架构重构

日期：2026-11-11。本轮保留现有数据与交互模型，替代2026-11-10的暗色浮层和四军Parallel泳道方案。当前消息中没有实际参考图附件，按用户文字明确的档案纸面、军事行军图方向实施，没有复制外部参考路线。

## 开始前核对

实际技术为MapLibre GL JS 6.17.0、React reducer、原生历史RAF及Vite本机研究媒体预览。路线来自现有routes.json的17段GeoJSON方向示意，地点为40项现代地域参考；缺坐标仍为null。原时间轴以四军泳道呈现，点击事件通过一个select action同时调时、暂停、打开资料；勾选改变visibleArmies，右栏通过PLC/EVT/AST/DOC/SRC关联数据。

未初始化新工程、未替换地图引擎、未新增依赖、未重做首页。已有工作区修改完整保留，本轮目标文件快照位于 `output/playwright/map-redesign-20261111/before/`。

实际读取并应用frontend-design与ui-ux-pro-max：以地图路线为视觉重心，保留键盘、可见焦点和原生滑块；低优先级阶段列表折叠，所有事件仍在资料索引和上下事件控制中。没有引入额外持续装饰动画、重噪点或生成图片。

## 主要改造

- 档案纸面：米黄、浅棕、褐色，轻微纸面折痕与边缘晕染，双线图框。标题保留本地宋体、首页字标字体；导航为深褐，左右资料栏改为浅纸面。地形阴影降低，现代道路和无关POI隐藏，水域及地名低饱和。
- 视野：MapLibre画布改为左右面板之间的实际可见区域，按现有路线地域坐标拟合，使用小幅内边距。放大主分布区域，不以全国轮廓为初始构图；没有平移地理点、裁掉真实数据或改造坐标。
- 路线：从固定3px改为随缩放约3.8—7px，使用浅纸色衬线、较长虚线和同色方向箭头。箭头只表示原有方向段，不补接断线，不把区域示意伪装成精确道路。
- 部队：红一方面军（中央红军）深红 `#9B302A`，红二方面军及前身赭黄 `#A27124`，红四方面军蓝灰 `#42616B`，红二十五军橄榄绿 `#50613B`。图层、勾选项、图例、资料标签共用展示令牌；原历史JSON配色不改写。
- 信息结构：保留全部显示/隐藏、独立勾选、突出；增加明确的“仅此军”快捷操作。“按历史阶段查阅”折叠，图例优先。红二方面军分类保留前身及当前时称提示，避免提前使用后来的番号。
- 单一时间轴：删除四军事件泳道DOM，改为一个当前日期、一条日期滑轨和最多6组简要里程碑提示。上一/下一事件、起点、总览、播放/暂停、1/2/4倍速及跟随均保留。密集候选仍可打开选择列表，完整史料不丢弃。
