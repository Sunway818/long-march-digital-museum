# 四渡赤水完整专题与历史展陈推广

2026-11-14。依据用户提供的《历史事件展陈系统深化任务》实施；用户已明确认可最新版展厅视觉，本轮直接延用，不重新设计首页或地图。

## 实际交付与入口

在地图中选择任一次赤水渡河，右侧提供“阅读四渡赤水完整专题”。原“深入了解”继续打开该次渡河的独立展陈，不合并四个事件ID。完整专题按序章、四渡四章、终章组成六段连续场景，普通滚动、章节导航、方向图节点均可连续阅读。

右侧索引增加默认折叠的“历史专题展厅”，可直接打开12个迁移节点。原38项具地域定位的精选索引规则保留；输入事件编号或专题名称时可检索迁移目录，未定位的草地节点也能阅读，定位按钮仍按原坐标状态禁用。

## 用户原稿与史实核对

原稿原文保存在[用户叙事底稿](history/CHISHUI_USER_NARRATIVE.md)，结构化为`src/data/history/exhibitions/chishui-draft.json`。正文和解读共64段，四章解读共26段；逐段对比底稿，不改关键日期、方向或历史结论。序章和终章、加粗强调、四章解读标题均保留。四次独立事件的正文也从同一初稿派生，避免两套文字互相漂移。旧一渡叙事仍在原文件中保留沿革；所有新文字保持draft/pending，没有覆盖已审核正式文本。

本轮读取：

- [中央党史和文献研究院长征90周年专题](https://www.dswxyjy.org.cn/GB/427277/462086/index.html)：四次渡河、后续乌江/金沙江和其他节点的基本时序。
- [《四渡赤水出奇兵》](https://www.cac.gov.cn/2016-08/22/c_1119430867.htm)：渡河日期、元厚/猿猴场、土城战斗、2月25日晚攻占娄山关、随后反扑和再占遵义，以及乌江/金沙江行动。新增SRC-0104。
- [四渡赤水纪念馆研究正文](https://www.sdcs1935.com/html/yanjiu/sdcs/202104/fd2e1eb33ba35bb1.shtml)：四阶段与现存一渡、二渡要图，沿用SRC-0015。
- [宫玉振的决策分析](https://www.bimba.pku.edu.cn/wm/xwzx/jsasd/gyz/413655.htm)：作为解释参考，新增SRC-0105。其二渡起始日为19日，与本项目采用18—21日范围不同；不据此改用户原稿或事件日期。三渡16/17日、计划逐步形成与解释性判断仍需人工复审。
- 用户提供的[军网参考链接](https://www.81.mil.cn/2019zt/2019-07/31/content_9573434.htm)本轮超时，作为SRC-0106保留，未据此认定事实已经核实。

其他节点优先复用原登记与证据定位，并复读SRC-0033、SRC-0041、SRC-0045、SRC-0037等页面。若尔盖遗址页SRC-0043本轮读取受限，草地材料继续以已有登记为基础，保持待审，没有补写未经依据的分路或逐日行军。新来源独立登记在`src/data/history/exhibitions/sources.json`，没有改原始来源JSON。

## 素材权限、遗漏与人工审核

完整四渡专题8张既有素材；12个推广节点17张，去重后本轮展陈共24张，**0张生成、0张新增下载、0张升级为公开授权**。已与原下载登记核对SHA，24个原文件保持一致，统计位于`output/playwright/exhibition-deepening-reports/material-audit.json`。图像仍通过既有loopback研究接口读取，不复制进public/dist。原登记的其他图片、来源和文献链接保留在文末折叠目录中，不因主画面精选而删除。

本机无参数仍为干净设计预览，review=1显示审核信息；review=0与远程只接纳ready/verified素材和正式内容。现有图像公开许可均未完成，新的正文与本站解读也保持草稿，不将本机可用等同于可公开发布。

待完善包括：通道事件可用代表影像、将台堡当日影像与文献、四个渡口的确址及分军日程、敌军可定位部署资料、草地完整分路、图像拍摄年代/原片与公开许可、争议手稿作者和版本。遵义AST-0011、年代有争议的AST-0015等不作为本轮主要展品；原链接仍可审阅。人物专题等尚无本轮完整独立叙事，未为填充生成履历、现场发言或历史引语。

人工应重点复审：64段用户稿及本站解释的边界、三渡范围及两种二渡起始口径、各地点异名、所选照片的性质与署名、文献数字图像能否支撑完整原文、以及公开展示许可。本轮不作史实或版权“全部审核通过”的结论。
