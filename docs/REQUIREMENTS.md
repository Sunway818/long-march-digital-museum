## 非功能需求

| 编号 | 要求 | 验收目标 |
| --- | --- | --- |
| NFR-01 | 历史真实性 | 正式发布的历史事实、日期、人物和路线断言具备来源；无来源的结论不发布；争议和概略精度可见 |
| NFR-02 | 桌面优先与窗口韧性 | 设计基准 1920×1080，必测 1366×768，补测 1536×864/1440×900/1280×720；窗口缩至 1024×640、800×600 时允许自然纵向增长和列重排，不得严重重叠、裁断正文或页面级横向溢出。不要求手机专属导航、地图、底部对话框 |
| NFR-03 | 无障碍 | 以 WCAG 2.2 AA 为目标：可见焦点、文字对比度、键盘替代拖拽、面板关闭与焦点恢复、减少动态效果 |
| NFR-04 | 桌面性能 | 第 11 天在固定 Windows 演示机和桌面 Lighthouse 配置测量：LCP≤2.5s、CLS≤0.1、TBT≤200ms 为实验室目标；真实 INP≤200ms 需现场数据。取消移动模拟为必验门槛 |
| NFR-05 | 桌面交互性能 | Windows 桌面地图拖动/动画目标 50–60fps，持续低于 30fps 降低装饰效果；输入反馈 p95≤100ms；记录 CPU/GPU、硬件加速、浏览器缩放和样本，不为手机增加复杂分支 |
| NFR-06 | 工程质量 | TypeScript 严格模式；数据/视图/计算分离；核心时间计算单测和联动流程测试通过；锁文件纳入版本管理 |
| NFR-07 | 兼容性 | Windows 桌面 Chrome、Edge 为必测，记录测试日实际版本；Firefox 为补充，Safari/iOS/Android 手机测试不构成本轮交付门槛。未测不宣称支持 |
| NFR-08 | 可运行与交付 | 新目录按说明安装、启动、构建和预览通过；控制台无未处理错误；报告链接与截图对应最终提交 |
| NFR-09 | 故障处理 | 缺图、数据空集、无有效日期、非法 URL 参数和模块卸载均有明确降级；失败不阻塞正文 |
| NFR-10 | 素材管理 | 首屏静态优先；图片声明尺寸、响应式加载，非首屏懒加载；字体子集与本地备选；无强制音频自动播放 |

性能值是待验证的工程目标，不是当前测量结果。[测试计划](TEST_PLAN.md)定义环境和证据格式。

## 已确认设计边界与评审资产

首页方案 A 全屏电影式构图；正文使用思源宋体，导航、日期控件、地图标签等功能文字使用思源黑体。首页标题已确认使用钟齐志莽行书（ZhiMangXing-Regular.ttf，原生 400）。已完成三套实际字体文件渲染比较，证据保留；禁止用字体名称描述或生成图冒充实际字形。具体字号、间距和位置仍需桌面原型验证。

红金黑方向已认可，暖红 #8A2E22 为优先候选，实际色值仍须结合用户原图评审；路线色与符号保留候选，待地图原型验证后确认。原图作者/创作方式/授权待补充，不制作原图派生文件或公开发布。小屏完整影像带与底部对话框保留为未来候选，若另行启动手机适配，必须验证可读性、操作便利和地图可视面积；当前不增加相关实现或手机验收任务。

1920×1080/1366×768 是设计画幅；实际验收另记录屏幕分辨率、Windows 缩放、浏览器 zoom、innerWidth/innerHeight 和 F11 状态，不能将显示器分辨率直接当 CSS 视口。
