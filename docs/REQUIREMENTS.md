# 项目需求规格

版本：0.2；更新：2026-11-07。Desktop-first：以 Windows 电脑向教师展示为主，1920×1080 为设计基准，兼容 1366×768 笔记本。首页已选择方案 A，标题字体和精确色值待评审；当前功能均待实现。P0 为交付必需；P1 为完整体验；P2 为增强。

## 功能需求与验收

| 编号 | 优先级 | 功能 | 可核验的验收条件 |
| --- | --- | --- | --- |
| FR-01 | P0 | 全站入口和导航 | 六模块均可到达，章节名称明确；键盘导航可用；深链接刷新不丢失定位 |
| FR-02 | P1 | 首页历史序章 | 具有全屏影像、主题标题和进入展馆入口；标题动画完成或跳过后内容可读；影像失败有静态替代 |
| FR-03 | P0 | 历史时间轴 | 事件依历史时间排序，日期精度可见；选择事件可进入地图或详情，来源可查看 |
| FR-04 | P0 | 总览地图 | 默认完整地图；各部队独立路线、图例、线型/文字区分；不依赖颜色表达全部信息 |
| FR-05 | P0 | 时间驱动路线 | 拖动、键盘调时后，所有可见部队路线和地点在同一时间状态下更新；前后拖动可逆 |
| FR-06 | P0 | 地点资料 | 点击/键盘激活地点打开资料面板，显示事件、时间、相关部队、引用和路线精度说明 |
| FR-07 | P0 | 双向联动 | 选择事件定位日期；地图点击触发一次调时和选择，不能循环更新；历史时间轴与地图共享同一时间状态 |
| FR-08 | P0 | 播放控制 | 默认暂停；播放、暂停、0.5×/1×/2×可用；到终点停止；后台和离开模块暂停，无后台跳时 |
| FR-09 | P0 | 部队筛选 | 可分别隐藏/显示；筛选不改变全局时间；全部关闭有提示；不得把不同部队合并成一条路线 |
| FR-10 | P1 | 历史瞬间 | 会议、战役、重大事件按核实清单展示；进入/关闭详情顺畅，返回原阅读位置 |
| FR-11 | P1 | 英雄人物 | 人物档案、贡献、所属关系及相关事件具有独立引用，不编造引语、照片或履历 |
| FR-12 | P1 | 精神传承 | 历史价值与时代意义分层表达，史实、引用、作者阐释有清晰边界 |
| FR-13 | P1 | 来源和媒体说明 | 可查询具体参考资料和图片出处、授权状态；装饰性生成图不能冒充历史照片 |
| FR-14 | P2 | 单部队模式 | 进入时只显示目标部队且适配视野；退出恢复原筛选/视野，不改变时间 |
| FR-15 | P1 | 章节滚动叙事 | 内容先可阅读再增强动画；滚动不改写地图时间，除非明确点击“查看该事件” |

## 非功能需求

| 编号 | 要求 | 验收目标 |
| --- | --- | --- |
| NFR-01 | 历史真实性 | 正式发布的历史事实、日期、人物和路线断言具备来源；无来源的结论不发布；争议和概略精度可见 |
| NFR-02 | 桌面优先与窗口韧性 | 设计基准 1920×1080，必测 1366×768，补测 1536×864/1440×900/1280×720；窗口缩至 1024×640、800×600 时允许自然纵向增长和列重排，不得严重重叠、裁断正文或页面级横向溢出。不要求手机专属导航、地图、底部对话框 |
| NFR-03 | 无障碍 | 以 WCAG 2.2 AA 为目标：可见焦点、文字对比度、键盘替代拖拽、面板关闭与焦点恢复、减少动态效果 |
| NFR-04 | 桌面性能 | 第 11 天在固定 Windows 演示机和桌面 Lighthouse 配置测量：LCP≤2.5s、CLS≤0.1、TBT≤200ms 为实验室目标；真实 INP≤200ms 需现场数据。取消移动模拟为必验门槛 |
| NFR-05 | 桌面交互性能 | Windows 桌面地图拖动/动画目标 50–60fps，持续低于 30fps 降低装饰效果；输入反馈 p95≤100ms；记录 CPU/GPU、硬件加速、浏览器缩放和样本，不为手机增加复杂分支 |
| NFR-06 | 工程质量 | TypeScript 严格模式；数据/视图/计算分离；核心时间计算单测和联动流程测试通过；锁文件纳入版本管理 |
| NFR-07 | 兼容性 | Windows 桌面 Chrome、Edge 为必测，记录测试日实际版本；Firefox 为补充，Safari/iOS/Android 手机测试不构成本轮交付门槛。未测不宣称支持 |
| NFR-08 | 可运行与交付 | 新目录按说明安装、启动、构建和预览通过；控制台无未处理错误；报告链接与截图对应最终提交 |
| NFR-09 | 故障处理 | 缺图、数据空集、无有效日期、非法 URL 参数和模块卸载均有明确降级；失败不阻塞正文 |
| NFR-10 | 素材管理 | 首屏静态优先；图片声明尺寸、响应式加载，非首屏懒加载；字体子集与本地备选；无强制音频自动播放 |

性能值是待验证的工程目标，不是当前测量结果。[测试计划](TEST_PLAN.md)定义环境和证据格式。

## 已确认设计边界与评审资产

首页方案 A 全屏电影式构图；正文使用思源宋体，导航、日期控件、地图标签等功能文字使用思源黑体。首页标题优先评审钟齐志莽行书，并以至少三套实际字体文件渲染“伟大征程”进行比较，禁止仅靠字体名称或生成图冒充字形。字体最终选择仍待用户确认。

红金黑方向已认可，实际色值须结合用户原图评审；路线色与符号保留候选，待地图原型验证后确认。原图作者/创作方式/授权待补充，不制作原图派生文件或公开发布。小屏完整影像带与底部对话框保留为未来候选，若另行启动手机适配，必须验证可读性、操作便利和地图可视面积；当前不增加相关实现或手机验收任务。

1920×1080/1366×768 是设计画幅；实际验收另记录屏幕分辨率、Windows 缩放、浏览器 zoom、innerWidth/innerHeight 和 F11 状态，不能将显示器分辨率直接当 CSS 视口。
